# 📋 カルテスキャン

> iPad で動く医療現場向けカルテ写真スキャン PWA

**GitHub Pages（動作デモ）**
https://queenproducejapan18-cpu.github.io/-karute-scan/

---

## 概要

医療施設で約 400 人分・2,000 枚以上の紙カルテを電子化するために開発した iPad 専用の Progressive Web App（PWA）です。

専用アプリのインストールや特別な機器は不要で、Safari からホーム画面に追加するだけで即日運用できます。

---

## 解決した課題

| 課題 | 解決策 |
|---|---|
| 紙カルテを1枚ずつ撮影・整理する作業が煩雑 | 患者番号・氏名を入力するだけで撮影→自動命名→保存が完結 |
| 撮影した写真が患者ごとに整理されない | iOS ショートカットと連携してフォルダ自動作成・ファイル移動 |
| ネット環境がない現場での使用 | Service Worker によるオフライン対応 |
| 作業の抜け漏れが怖い | 書き出し→ショートカット実行→完了の3ステップを強制する未完了ガード |

---

## 技術スタック

- **フロントエンド**：HTML / CSS / Vanilla JavaScript（フレームワークなし）
- **ストレージ**：IndexedDB（撮影した写真をブラウザ内に一時保存）
- **オフライン対応**：Service Worker（ネットワーク優先 + キャッシュフォールバック）
- **外部連携**：iOS ショートカット（URLスキームで患者情報を渡してフォルダ作成・ファイル移動を自動化）
- **配布**：GitHub Pages（サーバーレス・インストール不要）

## 画面遷移

```
起動（scr-init）
　↓
初回セットアップ（scr-setup）※初回のみ
　↓
患者入力（scr-start）
　患者番号（数字）・患者名（カタカナ）を入力
　↓
撮影（scr-scan）
　タップで撮影 → IndexedDB に自動保存
　↓
保存完了・選択（scr-choice）
　① 書き出し（navigator.share → ファイルアプリへ）
　② ショートカット「カルテ整理」を実行
　③ 完了して次の患者へ
　↓
終了（scr-end）
　本日の撮影実績を表示
```

## ファイル命名規則

撮影した写真は以下の形式で自動命名されます。

```
00123_ヤマダタロウ_20260412_01.jpg
 ↑       ↑           ↑       ↑
患者番号  患者名      撮影日  連番
（5桁）  （カタカナ） （8桁）（2桁）
```

## iOS ショートカット連携

PWA の制約（ファイルシステムへの直接アクセス不可）を iOS ショートカットとの連携で解決しています。

```
アプリ側
　↓ URLスキームで患者番号_患者名を渡す
　  shortcuts://run-shortcut?name=カルテ整理&input=00123_ヤマダタロウ

ショートカット「カルテ整理」
　① 入力値（患者番号_患者名）を受け取る
　② カルテスキャンフォルダ内に患者フォルダを作成
　③ カルテスキャン直下のファイルをフィルタ（名前が入力値で始まるもの）
　④ 各ファイルを患者フォルダに移動
　⑤ 移動元のファイルを削除
```

## 設計上の工夫

**未完了ガード**
書き出し・ショートカット実行が完了しないと次の患者に進めない設計にしました。400人規模の運用では作業の抜け漏れが致命的になるため、ステップを強制する仕組みを入れています。

**モジュール分割の思想**
フォルダ作成とファイル移動を同一ショートカット内に入れつつ、処理の責任範囲を明確にしています。失敗時にどのステップで問題が起きたかを特定しやすくするためです。

**IndexedDB の即時クリーンアップ**
書き出し完了後に IndexedDB からレコードを削除します。長期運用での肥大化を防ぎ、患者情報が端末内に残り続けるリスクを最小化しています。

**MIMEタイプの補正**
Safari が画像を異なるMIMEタイプで保存する場合があるため、IndexedDB から取り出す際に `image/jpeg` を明示的に設定してテキストファイルとして書き出されるバグを防いでいます。

## セキュリティ

- 患者データはすべて **iPad 内のローカルストレージのみ** に保存されます
- GitHub Pages はアプリのコードを配信するだけで、患者データを受け取るサーバーはありません
- 書き出し完了後に IndexedDB からデータを削除します
- 運用上は作業終了後に iPad の WiFi をオフにすることを推奨しています

- **iOS**：14 以降

## 開発の背景

医療現場での紙カルテ電子化プロジェクトにおいて、専用スキャナや業務システムを導入せずに即日運用できるツールが必要でした。現場スタッフが対面でサポートできる前提で、操作を最小化・ミスが起きにくい設計を優先しました。
